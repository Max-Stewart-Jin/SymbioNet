# SymbioNet

**SymbioNet: Symbiotic Cross-Modal Completion Network for Hyperspectral and LiDAR Joint Classification**

SymbioNet is a research project on robust joint classification of hyperspectral imagery (HSI) and LiDAR data under degraded observations and missing modalities. The method investigates gated cross-modal fusion and masked training for reliable prediction.

**Repository status:** This is an initial project page. The full research code, datasets, trained weights, and experiment results have not been published here.
